## Prettier og CSS validator

[Prettier](https://prettier.io/) í [vscode](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) er notað til að forma bæði HTML og CSS. [CSS validation þjónusta W3C](https://jigsaw.w3.org/css-validator/) er notuð til að staðfesta að CSS sé gilt.
